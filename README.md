## 🔁 DealLoop & 🔐 DealLocker

A two-part web platform that helps users **store, organize, and share coupon codes**
in a clean and user-friendly way — built entirely with **HTML, CSS, and JavaScript**.

---

## 🚀 Project Overview

**DealLocker and Deal Loop together form a closed-loop coupon management system.**

- **DealLocker** → a private coupon wallet
- **Deal Loop** → a public deal discovery platform

Designed to reduce clutter, improve organization, and encourage community-driven savings.

---

## 🔐 DealLocker (Private Coupon Wallet)

✔ Save coupons from anywhere  
✔ Organize by category, brand & expiry  
✔ View all saved coupons in one place  
✔ Delete or manage deals anytime  
✔ Share selected coupons to Deal Loop  

> Think of DealLocker as your **digital wallet for discounts**.

---

## 🔁 Deal Loop (Public Deal Sharing)

✔ Browse deals **category-first**  
✔ No clutter — see details only when needed  
✔ Discover community-shared coupons  
✔ Updates sync automatically  

> Deal Loop is where **saved deals become shared wins**.

---

## 🧠 Design Philosophy

- 🔀 Clear separation between private & public data
- 🧹 Minimal UI clutter
- 🌙 Dark theme with green highlights
- 🎯 Focused, intentional animations

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **Browser localStorage**

No frameworks. No backend. Lightweight and fast.

---

## 🔄 How It Works

1️⃣ Save coupons in DealLocker  
2️⃣ Data stored locally in browser  
3️⃣ Choose coupons to share  
4️⃣ Appear publicly in Deal Loop  
5️⃣ Delete once → removed everywhere
